# 👨‍💻 Portfólio — Luiz Augusto

Site portfólio de página única do desenvolvedor **Full Stack Python/Django** Luiz Augusto.

## 🌐 Acesso

Publicado no GitHub Pages: [luizaugusto2006.github.io](https://luizaugusto2006.github.io)

## ✏️ Como editar

- `index.html` — conteúdo das seções (Sobre, Projetos, Habilidades, Contato).
- `css/style.css` — estilos e tema (dark, acento azul).
- `js/script.js` — filtro de projetos, menu mobile e interações.

### Personalizar contato
Edite em `index.html`:
- **WhatsApp:** substitua `55SEU_NUMERO` pelo seu número com DDI/DDD.
- **LinkedIn:** substitua `SEU_LINKEDIN` pelo slug do seu perfil.
- **GitHub:** já aponta para `github.com/luizaugusto2006`.

### Adicionar um projeto
Copie um bloco `<article class="card">` dentro de `#projetos` e ajuste título, descrição, tags e links.

## 🚀 Deploy

O site é estático e roda no **GitHub Pages** automaticamente a partir da branch `main`.
